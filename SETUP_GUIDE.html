01
Create Meta WhatsApp Business App
~15 min
Go to Meta for Developers
Visit developers.facebook.com → Click My Apps → Create App
Choose App Type
Select "Business" as app type → Enter app name (e.g. "TRIDENT Agent") → Click Create App
Add WhatsApp Product
In your app dashboard → scroll to "Add Products" → Find WhatsApp → Click Set Up
Get Your Credentials
Go to WhatsApp → API Setup. Note down:
• Phone Number ID (looks like: 123456789012345)
• WhatsApp Business Account ID
• Temporary Access Token (valid 24h for testing)
⚠️ The temporary token expires in 24 hours. For production you'll generate a permanent token in Phase 4.
Add a Test Recipient
On the API Setup page → "To" field → click Manage phone number list → add your personal WhatsApp number. Meta requires this for sandbox testing.
02
Deploy to Railway via GitHub
~10 min
Push code to GitHub
Create a new GitHub repo and push the agent code:
# In the whatsapp-agent folder
git init
git add .
git commit -m "feat: TRIDENT WhatsApp AI Agent"
git remote add origin https://github.com/YOUR_USER/trident-wa-agent.git
git push -u origin main
Create Railway Project
Go to railway.app → New Project → Deploy from GitHub Repo → Select your repo → Railway auto-detects Node.js and deploys.
ℹ️ Railway gives you a free public URL like trident-wa-agent.up.railway.app — this is your webhook URL.
Add Environment Variables in Railway
In Railway → Your service → Variables tab → Add each:
VariableValue source
WHATSAPP_ACCESS_TOKENMeta API Setup page
WHATSAPP_PHONE_NUMBER_IDMeta API Setup page
WEBHOOK_VERIFY_TOKENAny secret string you choose
ANTHROPIC_API_KEYconsole.anthropic.com
03
Connect Meta Webhook to Railway
~5 min
Copy Your Railway URL
In Railway → your service → Settings → copy the public domain. It looks like:
https://trident-wa-agent-production.up.railway.app
Register Webhook in Meta
Meta App Dashboard → WhatsApp → Configuration → Webhook section:

• Callback URL: https://YOUR-RAILWAY-URL/webhook
• Verify Token: The same string you set as WEBHOOK_VERIFY_TOKEN

Click Verify and Save
Subscribe to messages
After verifying, under Webhook Fields → click Subscribe next to messages
Test It!
Send a WhatsApp message to your test phone number. You should get a Claude AI reply within 2–5 seconds! 🎉
✅ Check Railway logs in real-time: Railway → Service → Deployments → View Logs
04
Go Production — Permanent Token
~20 min
Create a System User in Meta Business Manager
Go to business.facebook.com/settings/system-users → Add → set role as Admin
Generate Permanent Access Token
System User → Generate New Token → Select your app → Enable permissions:
whatsapp_business_messaging, whatsapp_business_management

Copy the token — this never expires. Update Railway env var.
Add Real Phone Number
Meta → WhatsApp → Phone Numbers → Add Phone Number → verify via SMS/call. After adding, update WHATSAPP_PHONE_NUMBER_ID in Railway with the new number's ID.
⚠️ Free tier: 1,000 conversations/month free. After that, Meta charges per conversation (~$0.005–$0.08 depending on country).
